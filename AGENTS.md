# REVO Home Save
Read README.md, design.md and docs/launch-checklist.md before making changes.
Stack: TanStack Start + React + TypeScript + Tailwind CSS 4 + Vite + Nitro for Vercel. Node 24, npm.
Do not add authentication, accounts, profile icons, member areas, contact forms, databases or app-style bottom navigation.
Keep programme terms, costs, earnings and support claims unasserted until owner-approved. Do not use the reference site's personal referral links or identity.
Use src/config/site.ts for outbound URLs and src/lib/seo.ts for route metadata. Keep previews noindex. Never expose secrets through VITE_ variables.
After changes run npm run typecheck, npm run check and npm run build. Do not deploy without a deployment request.
