# REVO Home Save
A local, server-rendered marketing-site starter prepared for the REVO opportunity project. The homepage integrates the supplied Stitch composition as responsive React components. Content and legal information still require owner approval before launch.

## Start
Use Node **24 LTS** (`nvm install` then `nvm use` if you use nvm). The machine's original Node 22.11 is too old for current TanStack/Vite packages.

```sh
npm install
cp .env.example .env.local
npm run dev
```
Open http://localhost:3000. Dependencies are already installed on this machine. If npm reports a cache permission issue, use `npm install --cache /private/tmp/revo-npm-cache` rather than changing ownership of your home folder.

## Structure
- `src/routes/`: server-rendered pages plus robots.txt and sitemap.xml endpoints.
- `src/components/layout/`: shared header and footer; `src/components/ui/`: reusable controls.
- `src/content/`: editable opportunity copy.
- `src/config/site.ts`: site identity, launch indexing gate and outbound links.
- `src/lib/seo.ts`: route titles, descriptions, canonical and Open Graph metadata.
- `src/styles.css`: REVO tokens, responsive bento foundation and Tailwind 4.
- `public/`: favicon, social artwork, images and optional fonts. Inter/Manrope are self-hosted from Fontsource.
- `design/stitch/`: put the Stitch export here. `design.md` is the design brief.
- `docs/launch-checklist.md`: remaining content and production requirements.

## Checks
```sh
npm run typecheck
npm run check
npm run build
npm run preview
```
`npm run format` formats source. `npm run check -- --write` applies Biome fixes. The route tree is generated by TanStack; do not edit it manually.

## SEO and deployment
Pages render on the server. Each page has metadata. Canonicals and absolute social-image URLs use VITE_SITE_URL; no address is invented when it is unset. The sitemap uses the same public-page registry. Draft legal pages remain noindex and are excluded from the sitemap. This starter blocks indexing by default. Production needs both a configured origin and VITE_SITE_INDEXABLE=true. Vercel previews always remain noindex. Environment changes require a rebuild.

Vercel uses the official TanStack CLI's Nitro integration and vercel.json framework detection. No deployment, account linking or DNS changes have been performed. Configure the production URL and public link variables in Vercel when ready. Do not put secrets in VITE_ variables.

No analytics, tracking, authentication, contact capture or backend database has been added. No fabricated business schema or FAQ structured data is emitted; add factual structured data when the operator and final content are approved. SEO scaffolding supports crawlability and sharing; it does not promise rankings.
